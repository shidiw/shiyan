# Struct3D Hypothesis Elimination Contract

## 1. Objective

The final theory-facing path has no external upstream mathematical objects beyond
one finite observation

\[
X=(x_0,\ldots,x_{n-1})\in(\mathbb R^3)^n,\qquad n\ge 1.
\]

All former boundaries are deterministic functions of the same X:

\[
X\to A_{\max}(X)\to\Gamma(X),M(X),G_B(X),N_X,S_X,C_R(X),\Phi_X.
\]

They are now packaged as the first-class
`ObservationDerivedBoundaries` object in
`structure/theory_observation_boundaries.py`.  The canonical engineering path
is `ObservationDerivedPipeline.from_points(X)` followed by its `boundaries`
carrier.  Downstream theory code consumes this carrier rather than caller-
supplied mathematical families.

## 2. Boundary elimination

### A(X) and Gamma(X)

\[
\Omega_X=\{0,\ldots,n-1\},\qquad
A_{\max}(X)=\Pi(\Omega_X).
\]

`A(X)` is frozen as this maximal finite admissible family and
`Gamma(X)=A_max(X)` in the theory-facing finite core. Therefore both are
non-empty, finite, and closed under observation-index relabeling.

Implementation: `ObservationCandidateFamily`, exposed through
`ObservationDerivedBoundaries.A`, `.A_max`, and `.Gamma`.

### M(X)

\[
M(X)=\{m_{point},m_{line},m_{plane}\}.
\]

The models are fitted deterministically from the coordinates of X. They do not
consume semantic labels, primitive labels, learned parameters, or caller
hyperparameters. Coordinate-axis ties are resolved by the fixed coordinate
index rule.

Implementation: `ObservationModelFamily`, exposed as
`ObservationDerivedBoundaries.M`.

### G_B(X)

For every unordered pair of distinct observation indices,

\[
w_{ij}=\frac{1}{1+\|x_i-x_j\|/s(X)},
\]

where `s(X)` is the observation diameter. The boundary graph is therefore a
complete finite weighted graph for positive-diameter observations.

Implementation: `ObservationBoundaryGraph`, exposed as
`ObservationDerivedBoundaries.G_B`.

### N_X and S_X

For every X-derived Unit candidate `u`, `N_X(u)` is generated by one-index
insertion/deletion moves inside `Omega_X`. The proper subcandidate family
`S_X(u)` contains every non-empty proper support subset.

The important closure change is that these are no longer free-standing rules:
the complete finite families over all X-derived Unit candidates are frozen as
`ObservationNeighborhoodFamily` and `ObservationSubcandidateFamily`.

Implementation: `ObservationDerivedBoundaries.N_X` / `.S_X`, with
`.neighborhood(u)` and `.proper_subcandidates(u)` as deterministic projections.

### C_R(X)

The global candidate relation domain is the complete ordered pair set of
distinct X-derived Unit candidates:

\[
C_R(X)=\{(i,j):i\ne j\}.
\]

The World-local relation domain is not an external input; it is the canonical
restriction of this same X-derived object to the selected X-derived Unit
sequence. The actual relation set is then filtered by the observation-derived
predicate `Q_X`.

Implementation: `ObservationRelationCandidateDomain`, exposed as
`ObservationDerivedBoundaries.C_R` and restricted by
`.restrict_relation_domain(units)`.

### Phi_X

\[
\Phi_X:W_X\to\mathbb R^{23}
\]

is the deterministic coordinate map implemented by `represent_observation`.
Its map object is now also part of the same boundary carrier:
`ObservationDerivedBoundaries.Phi_X`.
It accepts only a World carrying the identical observation provenance context,
so a World from another observation cannot be silently represented by Phi_X.

## 3. Closed Stage 2D -> World -> Representation path

The canonical pipeline is

\[
X\to
(A,\Gamma,M,G_B,N_X,S_X,C_R,\Phi_X)
\to E_X\to P_X^*\to U_X\to R_X\to W_X
\xrightarrow{\Phi_X}\mathbb R^{23}.
\]

Stage 2D consumes `M(X)` and `G_B(X)` directly from the boundary carrier.
Stage 2F consumes `Gamma(X)`. Stage 2E receives only X-derived Unit
candidates and X-derived `N_X/S_X` projections. World construction derives
its relation candidate domain by restricting `C_R(X)` and applies only `Q_X`.
Representation is evaluated by the same first-class `Phi_X` map.

No external partition, model family, boundary graph, relation candidate set,
or representation extractor is needed on this path.

## 4. Compatibility with legacy theorem APIs

Low-level explicit-input constructors remain available for generic mathematical
regression tests. They are not the canonical raw-observation theory boundary.
The release-facing observation path is the pipeline above.

This distinction is intentional: compatibility APIs do not become hidden
hypotheses of the Struct3D observation theorem merely because they remain
callable.

## 5. Regression contract

`tests/test_hypothesis_elimination_pipeline.py` and
`tests/test_observation_derived_boundary_objects.py` verify:

1. `A(X)=A_max(X)` is the finite complete partition lattice.
2. `Gamma(X)=A_max(X)`.
3. `M(X)` and `G_B(X)` are observation-derived and finite.
4. `N_X`, `S_X`, and `C_R(X)` are first-class finite families/objects.
5. Stage 2D consumes the exact X-derived `M(X)` and `G_B(X)`.
6. World relation formation consumes an X-derived restriction of `C_R(X)`.
7. `Phi_X` is a first-class X-derived map and preserves the 23-D schema.
8. The entire boundary carrier is finite, non-empty, and quotient-compatible.
9. Observation-index permutation preserves the cardinality/contracts of the
   derived boundary objects.

Passing these tests establishes the repository implementation contract for the
observation-derived boundary layer. It does not by itself prove any universal
geometric semantics beyond the frozen definitions stated above.
