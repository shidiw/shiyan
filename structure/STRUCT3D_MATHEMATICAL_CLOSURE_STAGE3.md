# Struct3D Mathematical Closure — Stage 3: Relation Formation

## 1. Scope

Stage 3 closes the boundary between already-materialized Structural Units and
an explicit Structural Relation set.

The frozen world is still

`W = (U, R, Phi)`

and the graph remains

`G = (V, E)`

with vertices indexed by Units and edges copied exactly from `R`.

## 2. Relation admissibility

For Units `u_i, u_j`, define an explicitly supplied relation predicate

`Q(u_i, u_j) in {False, True}`.

A pair is admissible exactly when

`Q(u_i, u_j) = True`.

Stage 3A treats `Q` as an explicit mathematical input. It is not silently
instantiated by primitive equality, Euclidean proximity thresholds,
connectivity, curvature thresholds, or historical heuristics.

## 3. Stage 3B — Geometry → Relation Q

Stage 3B now closes one concrete geometry-derived relation predicate for 3-D
supports. Let `G_i` and `G_j` denote the continuous geometric supports of two
Structural Units. Define the common boundary-contact measure

`b_ij = H^2(partial G_i intersection partial G_j)`.

The geometry adjacency predicate is

`Q_adj(G_i,G_j) = 1  iff  b_ij > 0`.

Equivalently,

`Q_adj(G_i,G_j) = 1  iff  H^2(partial G_i intersection partial G_j) > 0`.

The relation type generated by this predicate is `adjacent` (positive-area
boundary contact). Zero contact measure does not create an adjacency relation.

### Why this is a mathematical predicate

1. `H^2` is the 2-dimensional Hausdorff measure appropriate to surfaces in
   three-dimensional space.
2. The predicate uses an exact sign test on a measure; no arbitrary numeric
   threshold is part of the theorem.
3. Under a rigid isometry `T`, Hausdorff measure is preserved, so
   `Q_adj(G_i,G_j) = Q_adj(TG_i,TG_j)`.
4. A simultaneous relabeling of Units changes indices only and leaves the
   underlying supports unchanged, so the geometric predicate is label-free.

The engineering implementation receives the pairwise value of `b_ij` as
explicit geometric evidence. For sampled point clouds, an estimator of
`H^2(partial G_i intersection partial G_j)` is an engineering approximation and
must not be confused with the exact mathematical quantity.

## 4. Candidate pair domain

Let `C_R` be an explicitly supplied finite set of ordered distinct index pairs:

`C_R subset {(i,j): 0 <= i,j < |U|, i != j}`.

The formed relation set is exactly

`R_Q = { r_ij : (i,j) in C_R and Q(u_i,u_j)=True }`.

Each relation carries an explicit type and evidence/provenance record.

No pair outside `C_R` can be added by the formation operator.

## 5. Formation rule

For an evidence record `e_ij=(type,payload)`,

`Form_Q(u_i,u_j) = r_ij`

iff `(i,j) in C_R` and `Q(u_i,u_j)=True`.

Otherwise no relation is materialized for that pair.

The endpoint constraints are part of the contract: endpoints must be distinct
and lie in the Unit domain.

## 6. Exact graph consequence

Once `R_Q` is formed,

`V = {0,...,|U|-1}`

and

`E = R_Q`.

Therefore the graph constructor is not a second inference mechanism. It is an
exact view of the formed relation set.

## 7. Theorem 3B.1 — Geometry invariance of adjacency

Let `T` be a rigid isometry of `R^3`. If

`b_ij = H^2(partial G_i intersection partial G_j)`,

then

`H^2(partial(TG_i) intersection partial(TG_j)) = b_ij`.

Consequently,

`Q_adj(G_i,G_j) = Q_adj(TG_i,TG_j)`.

### Proof

Rigid isometries preserve boundaries, intersections, and Hausdorff measure.
Therefore the contact measure is unchanged. Its strict positivity is therefore
unchanged, proving the predicate invariance. QED.

## 8. What is now closed

The following engineering behaviors are explicit and testable:

1. a relation requires an explicit admissibility predicate;
2. `Q_adj` has a precise geometry definition through `H^2` boundary contact;
3. zero contact measure is rejected and every positive finite contact measure is
   accepted;
4. no arbitrary positive threshold is hidden in `Q_adj`;
5. rigid transformations do not change the geometric truth value;
6. rejected candidate pairs produce no relation;
7. accepted pairs materialize with supplied type/evidence;
8. candidate endpoints are domain-checked;
9. self-relations are rejected;
10. duplicate candidate pairs are rejected;
11. no hidden relation inference occurs outside the candidate set.

## 9. Remaining theory boundary

Stage 3B closes **one** geometry-derived relation: positive-area boundary
contact. It does not claim that adjacency is the only possible Structural
Relation, nor does it derive arbitrary relation types from raw geometry.

Further relations such as orientation, containment, support, or assembly need
separate definitions and proofs. Symmetry, transitivity, and graph completeness
are not silently inferred from adjacency.

## 10. Closed chain

The current theory-facing chain is now

`X -> explicit A(X) -> E -> stable/minimal candidate -> Unit -> Geometry evidence -> Q_adj -> Relation set R -> Graph G -> World W`.

The downstream canonical, invariant, representation, and distance layers may
consume `W`, but must not back-propagate an unproved relation rule into Stage 3.

## Verdict

**Stage 3B is now mathematically closed for the boundary-contact adjacency
relation. The universal relation theory remains open beyond this explicitly
proved relation family.**
